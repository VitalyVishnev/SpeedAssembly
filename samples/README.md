# Samples

This folder stores controlled experiment inputs and expected outputs used to validate the converter on deliberately simple trees.

- `samples/speedtree/simple_tree/variants/` is the drop zone for XML export variants of the same simple SpeedTree 10 tree.
- `samples/expected_reports/` is for inspect reports chosen as regression artifacts.
- `samples/expected_usda/` is for generated USDA snapshots tied to selected sample variants.
