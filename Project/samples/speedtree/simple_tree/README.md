# Simple Tree Baseline

Place here the XML export variants of one intentionally simple SpeedTree 10 tree.

Recommended structure of the source tree:
- one trunk
- several primary branches
- several secondary branches
- two leaf meshes reused as instances

For each exported XML variant, keep a short note with:
- export setting profile name
- what hierarchy/grouping options were enabled
- whether bones, leaf refs, branch spines, and materials were exported
- any obvious differences in XML shape
