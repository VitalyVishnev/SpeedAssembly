# Обзор pipeline {#pipeline-overview}

SpeedAssembly связывает SpeedTree с новым Nanite workflow для растительности в Unreal Engine. Повторяющиеся листья и ветки остаются настоящими инстансами Nanite Assembly, скелет сохраняется для анимации ветра, а результат записывается в USDA для импорта в Unreal.

```text
SpeedTree
    ↓
Экспорт Raw XML
    ↓
SpeedAssembly: настройка геометрии, материалов и ветра
    ↓
USDA и дополнительные файлы при необходимости
    ↓
Unreal Engine: импорт и проверка ассета
```

!!! note "Unreal нужно подготовить"

    Перед импортом включите необходимые плагины и Nanite Foliage. См. [Подготовка Unreal Engine](../workflows/prepare-unreal.md).

## 1. Подготовьте и экспортируйте дерево {#1-prepare-and-export-the-tree}

Создайте дерево в SpeedTree как обычно, затем подготовьте к экспорту скелет, основную геометрию ствола и веток, ветки и листья для инстансинга, материалы и UV. Подготовка сцены и настройки экспорта описаны в [Подготовке SpeedTree](../workflows/prepare-speedtree.md).

Экспортируйте дерево в SpeedTree Raw XML. Именно этот файл нужно выбрать в **Input XML**.

## 2. Настройте дерево в SpeedAssembly {#2-configure-the-tree-in-speedassembly}

Откройте SpeedAssembly, выберите XML в **Input XML**, затем задайте путь и режим экспорта.

| Режим экспорта | Результат |
| --- | --- |
| **Skeletal Assembly** | Целое дерево с анимацией ветра на основе скелета. |
| **Static Assembly** | Визуально похожее дерево без скелета и анимации ветра. |
| **Skeletal Assembly Parts** | Отдельный Skeletal Mesh ассет для каждого повторяющегося элемента ветки или листвы. |
| **Static Assembly Parts** | Отдельный Static Mesh ассет для каждого повторяющегося элемента ветки или листвы. |

Обычный workflow для дерева использует **Skeletal Assembly**. Выберите режим Parts, если нужна библиотека веток или листвы, а не целое дерево.

### Wind {#wind}

Вкладка **Wind** задаёт базовое поведение групп костей для Dynamic Wind в Unreal. Настройки ветра можно изменить позже. Для подробной проверки и редактирования групп используйте отдельный Wind workflow.

### Geometry {#geometry}

Вкладка **Geometry** управляет каждой веткой или элементом листвы для инстансинга. Выберите источник для каждого элемента:

- **Use XML Mesh** сохраняет геометрию из SpeedTree.
- **Use FBX File** заменяет элемент внешним FBX mesh. Например, можно заменить лёгкую ветку из SpeedTree более детальной перед импортом.
- **Use Unreal Reference** использует уже импортированный ассет элемента в Unreal. Несколько деревьев смогут ссылаться на одну ветку без импорта новой копии для каждого дерева.

### Materials и UDIM {#materials-and-udim}

В **Materials** назначьте Object Path материалов Unreal для дерева, его веток и листвы. Скопируйте Object Path из Content Browser в Unreal. Все обязательные поля нужно заполнить до конвертации, чтобы Unreal правильно назначил материалы при импорте.

Для веток и листвы доступны следующие режимы материалов:

- **Single Material** назначает один материал всему элементу.
- **Material Slots** связывает используемые material slots из FBX с материалами Unreal.
- **Vertex Color Split** назначает два материала по vertex colors. Подготовьте mesh перед экспортом: полностью чёрные грани используют материал листвы, все остальные грани используют материал коры.

Vertex Color Split полезен, когда одному Leaf-генератору SpeedTree нужны материалы коры и листвы, а Raw XML сохраняет для него только одно назначение материала.

Для подходящих материалов можно также выбрать режим UDIM: оставить исходные UV, сдвинуть основной UV-канал в UDIM-тайл или сохранить его и записать смещение тайла во второй UV-канал. Используйте UDIM только с материалом Unreal, подготовленным для выбранного режима.

## 3. Конвертируйте и импортируйте {#3-convert-and-import}

После настройки нажмите **Convert to USDA**. SpeedAssembly запишет основной USDA для настроенного USD/Interchange workflow в Unreal.

Импортируйте файл в Unreal с настройками проекта и импорта, описанными для этого pipeline. Затем проверьте геометрию дерева, инстансы веток и листьев, материалы и скелет, если он предусмотрен режимом экспорта. Успешный импорт подтверждает структуру файла. Качество ветра, освещения, коллизий и разрушения нужно проверить отдельно.

## Дополнительные workflows {#advanced-workflows}

Используйте следующие инструменты после настройки основного дерева.

### Wind Preview {#wind-preview}

**Wind Preview** открывает отдельный viewport для проверки и редактирования групп ветра. Можно использовать XML-группы, автоматически создать группы по иерархии, добавить ручные переопределения и создать Dynamic Wind JSON из итогового набора видимых групп.

Можно также загрузить внешний FBX- или USD-скелет и создать Dynamic Wind JSON для растения, сделанного вне SpeedTree.

### Proxy Mesh {#proxy-mesh}

**Proxy Preview** создаёт упрощённый Static Mesh с необязательными коллизиями ствола. Он дополняет основное дерево в workflows для коллизий, distance fields и упрощённых теней.

Импорт Proxy Mesh как Static Mesh подтверждён. Проверьте distance fields и качество теней на конкретном ассете в целевой сцене Unreal.

### Fracturing {#fracturing}

**Fracture Preview** разбивает дерево на статичные части с pivot в корне дерева и позволяет экспортировать их с коллизиями. Это экспериментальный workflow подготовки ассетов для разрушения.

Экспортированные части содержат статичную геометрию. Их поведение при разрушении во время игры ещё нужно проверить в целевом проекте Unreal.

### Part Preview {#part-preview}

**Part Preview** открывает одну ветку или элемент листвы в отдельном viewport. Проверьте геометрию, разделение материалов или FBX slots и при необходимости немного уменьшите polycount перед основной конвертацией.
