# Proxy Mesh {#proxy-mesh}

Proxy Mesh повторяет общую форму растения в виде low-poly Static Mesh. Разместите его с тем же transform, что и видимое дерево, чтобы использовать для distance fields, коллизий ствола или упрощённых теней.

## Зачем нужен proxy? {#why-use-a-proxy}

- **Software Lumen:** Skeletal Mesh не создают Mesh Distance Fields. Статичный proxy может представить растение в distance fields. [Lumen Technical Details](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-technical-details-in-unreal-engine).
- **Коллизии:** proxy может содержать простые коллизии ствола типа Box или Capsule, независимо от mesh с анимацией ветра и без Physics Asset.
- **Тени вдали:** для деревьев далеко от игрока можно выключить тени на скелетном дереве и отдать их упрощённому статичному proxy. Тень потеряет движение ветра, зато скелетная анимация не будет сбрасывать shadow cache. [Virtual Shadow Maps](https://dev.epicgames.com/documentation/en-us/unreal-engine/virtual-shadow-maps-in-unreal-engine).

Proxy дополняет видимое растение. Скройте его от основной камеры, сохранив нужное участие в освещении или коллизиях.

## Создайте proxy {#generate-a-proxy}

1. В SpeedAssembly выберите **Input XML** растения и проверьте **Output USDA**.
2. Откройте **Geometry** и нажмите **Preview Proxy Mesh**.

![Preview Proxy Mesh во вкладке Geometry](../assets/images/proxy-open-preview.png)

3. Дождитесь mesh, затем настройте **Bounds Inflation** и **Density Resolution**, чтобы передать форму листвы.
4. Задайте **Final Polycount** и распределите полигоны между стволом и листвой через **Base Mesh Priority**.
5. Если нужны коллизии ствола, настройте **Generate Collision**, **Type**, **Height** и **Width**.
6. Проверьте **Output Path** и нажмите **Generate Proxy**.

![Proxy Mesh Preview с mesh, настройками генерации, коллизий и Output Path](../assets/images/proxy-preview-settings.png)

По умолчанию `<OutputStem>_proxy.usda` сохраняется рядом с основным Output USDA растения. Другой путь можно выбрать через **Browse** или ввести вручную. Если preview уже соответствует текущим настройкам, экспорт использует его без повторной генерации.

Для растений только из инстансов листвы со Scattered Rig генерация proxy недоступна.

## Настройте форму и polycount {#adjust-the-shape-and-polygon-budget}

SpeedAssembly отдельно упрощает ствол и уникальные ветки base mesh. Для инстансов элементов он создаёт объёмы по их bounds, объединяет их в поверхность листвы и упрощает её. Затем результаты для base mesh и листвы объединяются в один Proxy Mesh.

**Bounds Inflation** меняет размер объёмов элементов. **Density Resolution** определяет, насколько подробно сохраняется их общая форма. Увеличьте resolution, если крона теряет важные детали. Увеличение Final Polycount не восстановит детали, потерянные при построении поверхности.

**Final Polycount** задаёт целевое количество треугольников, а не гарантированный точный результат. **Base Mesh Priority** резервирует часть бюджета для base mesh. Уменьшите значение, чтобы оставить больше треугольников листве, или увеличьте, чтобы лучше сохранить форму ствола и веток.

**Remove Small Branches** удаляет мелкие несвязанные части base mesh перед упрощением. Используйте **Fuse Base Mesh Vertices**, если почти совпадающие швы между секциями ствола мешают упрощению.

## Сравните силуэт {#compare-the-silhouette}

Переключитесь с **Shaded** на **Silhouette Diff**, чтобы сравнить proxy с исходным растением с текущего ракурса:

- **Синий:** исходное растение выступает за пределы proxy.
- **Красный:** proxy выступает за пределы исходного растения.
- Совпадающие области показаны нейтральным цветом.

Покрутите растение и проверьте несколько ракурсов.

## Подгоните коллизии ствола {#fit-trunk-collision}

Включите **Generate Collision** и выберите **Box** или **Capsule**. Подгоните **Height** и **Width** под ствол.

Для растений с несколькими стволами по умолчанию создаётся один общий примитив. Включите **One Primitive per Stem**, чтобы подогнать отдельный примитив к каждому стволу и не перекрывать промежутки между ними.

Коллизии подгоняются по исходной геометрии ствола и скелету, а не по упрощённой поверхности proxy.

## Параметры {#parameters}

??? info "Показать подробности параметров"

    | Настройка | Действие | По умолчанию / диапазон |
    | --- | --- | --- |
    | <span id="final-polycount"></span>**Final Polycount** | Целевое количество треугольников готового proxy. Низкие значения уменьшают детализацию, высокие лучше сохраняют форму. Результат может содержать меньше треугольников или остаться выше цели, если дальнейшее упрощение повредит топологию. | 5,000; от 6 до 100,000 |
    | <span id="bounds-inflation"></span>**Bounds Inflation** | Масштабирует объёмы, построенные по bounds инстансов элементов. Низкие значения сжимают форму листвы, высокие расширяют её и могут соединять соседние объёмы. Не увеличивает base mesh. | 1.0; от 0.1 до 5.0 |
    | <span id="density-resolution"></span>**Density Resolution** | Voxel resolution вдоль самой длинной оси объёма листвы. Высокие значения сохраняют более мелкие детали, но увеличивают время генерации и расход памяти. При высоком resolution поверхность до упрощения может содержать миллионы треугольников. | 64; от 2 до 512 |
    | <span id="base-mesh-priority"></span>**Base Mesh Priority** | Доля целевого бюджета для базовой геометрии при наличии листвы. Низкие значения оставляют больше полигонов листве, высокие лучше сохраняют ствол и ветки. | 0.33; от 0 до 1 |
    | <span id="fuse-base-mesh-vertices"></span>**Fuse Base Mesh Vertices** | Сваривает вершины base mesh в пределах 1 мм перед упрощением, после удаления несвязанных частей. Помогает с почти совпадающими швами между секциями генераторов. Не объединяет отдельные стволы и не делает Boolean union. | Off |
    | <span id="remove-small-branches"></span>**Remove Small Branches** | Удаляет долю самых маленьких несвязанных компонентов base mesh, отсортированных по размеру. Чем выше значение, тем больше компонентов удаляется; ноль сохраняет все. Как минимум один компонент остаётся. Не вырезает мелкие ветки из непрерывного связного mesh. | 0.25; от 0 до 1 |
    | <span id="generate-collision"></span>**Generate Collision** | Добавляет в экспорт простые коллизии, подогнанные под ствол. Off экспортирует только proxy mesh. Переключение использует сохранённые исходные данные коллизий. | On |
    | <span id="collision-type"></span>**Type** | Выбирает Box или Capsule. Box используют направляющую геометрию `UBX_`, Capsule используют `UCP_`, ориентированные по подобранным осям стволов. | Box |
    | <span id="one-primitive-per-stem"></span>**One Primitive per Stem** | Off подгоняет один примитив под выбранные стволы вместе. On подгоняет отдельный примитив под каждый ствол. | Off |
    | <span id="collision-height"></span>**Height** | Доля длины основных осей стволов от их основания вверх, а не доля общих bounds proxy. Ноль убирает коллизии. | 0.5; от 0 до 1 |
    | <span id="collision-width"></span>**Width** | Множитель автоматически подобранной ширины ствола. Единица сохраняет подобранную ширину, ноль убирает коллизии. При подгонке не учитывается посторонняя геометрия кроны. | 1.0; от 0 до 10 |
    | **Shaded / Silhouette Diff** | Переключает обычный preview и геометрическое сравнение силуэтов. Не влияет на экспорт. | Shaded |
    | <span id="output-path"></span>**Output Path** | Точный путь USDA. По умолчанию `<OutputStem>_proxy.usda` рядом с основным экспортом. К заданному вручную пути дополнительный суффикс не добавляется. | На основе Output USDA |
    | **Browse** | Выбирает путь экспорта proxy. | |
    | <span id="generate-proxy"></span>**Generate Proxy** | Записывает текущие настройки mesh и коллизий. Использует готовый preview, если он соответствует настройкам, иначе сначала генерирует нужный mesh. | |

## Импортируйте в Unreal {#import-into-unreal}

Перетащите Proxy USDA в Content Browser с настройками из [Импорта в Unreal Engine](unreal-import.md). Он импортируется как Static Mesh с simple collision, если коллизии были экспортированы и **Import Collisions** включён.

Разместите proxy с теми же location, rotation и scale, что и дерево. Для shadow proxy выключите **Cast Shadow** у дерева и включите его у proxy.

## Навигация во viewport {#viewport-navigation}

- Левая кнопка мыши: orbit.
- Средняя кнопка мыши: pan.
- Колесо мыши: zoom.
- Двойной щелчок по mesh: фокус на выбранном участке.
- `F`: показать растение целиком.
