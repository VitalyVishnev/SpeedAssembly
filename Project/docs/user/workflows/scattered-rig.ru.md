# Scattered Rig {#scattered-rig}

Scattered Rig создаёт простой скелет для растений, целиком собранных из [инстансов Leaf-мешей](../wiki/choosing-assembly-parts.md). Режим подходит для травы, клевера, одуванчиков и другой низкой растительности, которой не нужен смоделированный ствол или скелет веток.

Режим появляется автоматически, когда [XML](../wiki/xml-usd-usda-json.md#xml-carries-the-speedtree-source) содержит инстансы листвы, но не содержит base mesh и скелета. SpeedAssembly создаёт кости при конвертации в скелетный mesh. В SpeedTree создавать их не нужно.

## Подготовьте граф SpeedTree {#build-the-speedtree-graph}

Используйте импортированные mesh в генераторах **Leaf**. Подготовьте их размер, pivot и ориентацию по инструкции [Подготовка SpeedTree](prepare-speedtree.md#prepare-repeated-branches-and-leaves). Оставьте **Use actual size** включённым.

### Участок без кластеров {#one-patch-without-clusters}

Подключите **Leaf** напрямую к **Tree** и распределите mesh по участку. Для такого графа доступны два режима: **Whole Mesh (Skinned)** и **Per Instance (Rigid)**.

![Граф SpeedTree с Leaf, подключённым напрямую к Tree](../assets/images/scattered-rig-direct-leaf.png)

### Участок из кластеров {#a-patch-made-of-clusters}

Соберите граф **Tree > Zone > Leaf**. Создайте несколько инстансов Zone, разместив в каждом несколько инстансов Leaf. Это добавит режимы **Per Cluster (Rigid)** и **Per Cluster (Skinned)**.

![Граф SpeedTree с Zone между Tree и Leaf](../assets/images/scattered-rig-zone-leaf.png)

SpeedAssembly читает экспортированную иерархию, а не имена генераторов. Для кластерных режимов нужны несколько промежуточных групп, в каждой больше одного инстанса; все инстансы должны входить в эти группы. Само наличие генератора Zone ещё не гарантирует такую структуру в экспорте.

![Участок травы из инстансов Zone и импортированных Leaf-мешей в SpeedTree](../assets/images/scattered-rig-grass-patch.png)

Экспортируйте XML с настройками из [Подготовки SpeedTree](prepare-speedtree.md#export-for-speedassembly). Не добавляйте геометрию веток или исходный скелет, если хотите использовать Scattered Rig.

## Выберите режим скелета {#choose-a-rig-mode}

Загрузите XML в SpeedAssembly и откройте **Wind**. Вместо **Skinning Quality** появится **Scattered Rig Mode**, а **Total bones** покажет количество создаваемых костей.

![Scattered Rig Mode и Average Instance Orientation во вкладке Wind](../assets/images/conversion-scattered-rig.png)

Во всех режимах есть одна корневая кость. Остальные кости отвечают за деформацию или жёсткое крепление.

| Режим | Геометрия и кости | Когда использовать |
| --- | --- | --- |
| **Whole Mesh (Skinned)** | Запекает все повторяемые mesh в один Skeletal Mesh. Всего две кости, деформация участка с двумя весами. Отдельных repeated parts не остаётся. | Участок, которому достаточно общего движения ветра и минимального скелета. |
| **Per Cluster (Rigid)** | Создаёт одну кость крепления на кластер и корневую кость. Инстансы внутри кластера движутся вместе без внутреннего изгиба. Первый кластер запекается в обязательный base mesh, остальные инстансы сохраняют инстансинг. | Движение по кластерам с сохранением повторяемой геометрии. |
| **Per Cluster (Skinned)** | Запекает все повторяемые mesh в один Skeletal Mesh. Создаёт одну кость деформации на кластер и корневую кость. Внутри каждого кластера используется деформация с двумя весами. | Кластеры, которым нужен собственный изгиб. Режим по умолчанию для найденных кластеров. |
| **Per Instance (Rigid)** | Создаёт одну кость крепления на каждый инстанс и корневую кость. Каждый mesh движется жёстко со своей костью. Один инстанс запекается в обязательный base mesh, остальные сохраняют инстансинг. | Независимое движение, когда движения по кластерам недостаточно. Большой scatter может создать дорогой скелет. |

Например, 20 кластеров дают 21 кость в обоих режимах Per Cluster. Участок из 500 инстансов даст 501 кость в режиме Per Instance.

Без кластеров два средних варианта недоступны. Начните с Whole Mesh или соберите граф с Zone, если нужно независимое движение кластеров. Выбирайте Per Instance, только если более подробное движение оправдывает количество костей.

### Расположение и ориентация костей {#bone-placement-and-orientation}

Whole Mesh использует среднюю позицию всех инстансов как pivot. Кластерные режимы используют среднюю позицию внутри каждого кластера. Per Instance ставит кость в точке крепления каждого mesh.

По умолчанию кости направлены почти вертикально, с небольшим наклоном для стабильной работы Dynamic Wind. Это простой rig из корня и дочерних костей, а не подробная цепочка вдоль каждой травинки.

Включите **Average Instance Orientation**, чтобы брать направления костей из ориентаций размещённых mesh. Whole Mesh усредняет весь участок, Per Cluster каждый кластер, а Per Instance использует ориентацию каждого mesh. Более крупные размещённые mesh сильнее влияют на усреднённое направление. Эта настройка меняет ориентацию костей, а не положение mesh.

## Настройте и экспортируйте {#configure-and-export}

1. В **Geometry** оставьте **Use XML Mesh** или выберите **Use FBX File** для mesh растений.
2. В **Materials** заполните пути к материалам Unreal. См. [Назначение материалов](materials-tab.md).
3. В **Wind** выберите **Scattered Rig Mode** и проверьте **Average Instance Orientation** и **Total bones**.
4. Настройте реакцию группы на ветер и **Ground Cover**. Созданный rig изначально использует одну группу ветра; для дальнейшего редактирования групп можно открыть **Advanced Wind Settings**.
5. В меню шестерёнки рядом с **Convert to USDA** выберите **Skeletal Assembly** и экспортируйте [USDA](../wiki/xml-usd-usda-json.md#usda-is-usd-you-can-read).
6. Нажмите **Generate Wind JSON**, чтобы отдельно экспортировать [настройки ветра](../wiki/xml-usd-usda-json.md#json-carries-the-wind-settings), затем выполните [Импорт в Unreal Engine](unreal-import.md), включая обязательную настройку **Transform Provider**.

**Use Unreal Reference** не поддерживается при скелетной конвертации Scattered Rig. SpeedAssembly нужна локальная геометрия для создания base mesh, в том числе в rigid-режимах. Используйте геометрию XML или FBX replacement.

Skinned-режимы импортируются как обычные Skeletal Mesh, поскольку вся повторяемая геометрия запечена. Rigid-режимы импортируются как Skeletal Nanite Assembly, если в результате остаются repeated parts.

Proxy Mesh и Fracturing недоступны для Scattered Rig. **Preview/Edit** остаётся доступным для проверки отдельных mesh и настройки их материалов.

## Настройки {#controls}

??? info "Подробное описание настроек"

    | Настройка | Действие |
    | --- | --- |
    | **Scattered Rig Mode** | Выбирает общее движение участка, движение по кластерам или по инстансам, а также деформируемую или жёсткую геометрию. Доступность кластерных вариантов зависит от экспортированной иерархии. |
    | **Average Instance Orientation** | Использует ориентации размещённых mesh для направлений костей. Если выключено, используются стандартные почти вертикальные направления. |
    | **Total bones** | Показывает размер создаваемого скелета для текущих настроек. |
    | **Refresh Wind Groups** | Повторяет анализ ветра после изменения исходного файла или rig. |
    | **Ground Cover** | Настраивает реакцию Dynamic Wind для низкой растительности. Значение записывается в Wind JSON. |
    | **Advanced Wind Settings** | Открывает viewport скелета для проверки и редактирования групп ветра. |

Реакция на ветер описана в [Как работает Dynamic Wind](../wiki/how-dynamic-wind-works.md), выбор размера repeated parts в [Выборе геометрии для инстансинга](../wiki/choosing-assembly-parts.md).
