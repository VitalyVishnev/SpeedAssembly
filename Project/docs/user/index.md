# SpeedAssembly

Convert SpeedTree Raw XML into Unreal-ready USDA while preserving the tree skeleton, unique base geometry, repeated parts, materials, and optional companion workflows.

[Start with your first conversion](getting-started/quick-start.md){ .md-button .md-button--primary }

</div>

SpeedAssembly is built specifically for the Unreal Engine 5.7–5.8 vegetation pipeline.


## Choose a workflow

<div class="grid cards" markdown>

-   **Main USDA conversion**

    Author a Skeletal Assembly, Static Assembly, or reusable parts library from SpeedTree Raw XML.

-   **Dynamic Wind**

    Inspect wind groups and generate the separate Dynamic Wind JSON used by the Unreal workflow.

-   **Proxy Mesh**

    Generate a lower-cost companion Static Mesh for collision, distance-field, and shadow workflows.

-   **Fracturing**

    Preview and export root-pivoted destructible tree pieces with optional collision geometry.

</div>
