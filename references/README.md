# Reference Assets

This folder stores real-world reference files that should stay separate from synthetic test fixtures.

## Layout

- `references/speedtree/xml/`
  Real exported SpeedTree Raw XML samples used for observed-schema research.
- `references/reports/inspect/`
  Deterministic inspect reports captured from real XML samples. These are useful as golden observed-schema artifacts.
- `references/notes/`
  Notes, reverse-engineering findings, mapping observations, and run-specific observations.

## Related immutable assets

- `vault/usd_schema/`
  Hand-authored or externally provided USDA skeletal assembly structures and preserved generated USDA artifacts with UE-facing API schemas.
